# Déploiement

- `lokkal/` — Nokker Lokkal, l'édition locale : compose, configuration du noyau, bac à sable (`sandboxd`), installeurs.
  Mode d'emploi : `docs/en/install.md`.
- `gateway/` — relais de la passerelle `nokker.app` (tunnel vers une instance locale, `docs/en/gateway.md`).
- `postgres/` — initialisation de la base (rôles, extensions) utilisée par les déploiements avec Postgres.
