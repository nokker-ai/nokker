Activer l'approbation biométrique

Cet appareil n'a pas encore de clé d'approbation. Nina va générer une paire de clés sur cet appareil ; la clé privée ne le quittera jamais et sera protégée par Face ID / Touch ID / l'empreinte de ton téléphone.

  • Génération de la clé (WebCrypto, ECDSA P-256)
  • Verrouillage derrière la biométrie du téléphone
  • Envoi de la clé publique seule à Nokker
  • Confirmation de l'appareil (code à valider)

Confirme cet appareil

La clé publique a été envoyée à Nokker. Il reste à confirmer cet appareil :

----

Confirme avec un code TOTP valide depuis un client déjà de confiance, ou demande à l'hôte : 

python -m nokker devices approve <code>

Cette page vérifie aussi automatiquement toutes les quelques secondes.
